# Investigation source and adaptations

The included focused probes, confidence rubric, Foundry routing, managed
Prometheus guidance and client, trace patterns and portal-link guidance were
adapted from a supplied observability contribution. Contributor permission to
ship this contribution is user-confirmed. No upstream LICENSE was found;
this record is not an MIT grant and invents no license terms.
The parent Microsoft specialist retains its separate upstream license.

The direct affected-path workflow composes those resources with the bundled
public diagnostics procedures. Supplied-evidence analysis requires no Python,
CLI, sign-in, network access or persistence. Adaptations retain scope, schema,
read budgets, caller probe review, causal counterevidence, organic trace routing,
benefit-gated existing SRE review and approved-fix/recovery handoffs.
The public Prometheus helper retains bounded scope, response validation,
no redirects and separate local-execution/network approvals.

The shared transaction-link helper is located in the health skill. Its default
host was adapted to `portal.azure.com`; URL construction tests do not verify
portal rendering or navigation. Offline tests do not establish host activation,
public service eligibility, telemetry access or live recovery. Test VS Code
and Copilot CLI separately; publication requires separate authorization.
