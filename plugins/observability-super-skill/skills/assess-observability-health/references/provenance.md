The integrated health assessment combines these resources with public
source/schema routing, Foundry correlation and query guidance in one bounded
workflow. Adaptations allow supplied-evidence analysis without cloud access,
Python, setup or persistence; retain actual operation discovery, nonsecret
context, shared budgets/window, ranked finding selection and direct
diagnostics/Foundry handoffs. Optional rendering requires an approved interpreter
and explicit sanitized-output persistence consent, never additional queries.

skill and its default portal host changed to `portal.azure.com`. Its routing and
encoding logic are retained; the helper is not byte-identical to its source.
