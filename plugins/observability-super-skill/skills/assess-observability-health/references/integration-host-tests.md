# Consolidated health integration: unrun host gates

Version 0.3.27 integrates instructions/helpers, not a deterministic dispatcher.
Run VS Code and Copilot CLI separately in fresh installed-package sessions,
outside the source checkout. Record host/version, actual instruction-load events,
entry/fallback, retained scope, planned versus executed operations, approval/
remaining budgets, skips, output/display and any manual help. A model label is
not loading evidence. No live access is authorized by these test instructions.

The [synthetic cases](integration-cases.json) are offline specifications, not
observed host behavior. Start with supplied evidence and no-cloud/no-script/
no-save approval. Verify:

1. General health loads stable `assess-observability-health` and its integrated
   resources, honors the shared pass and ranks handled failures; no second engine.
2. Explicit stable entry stays there. Honor an explicitly requested eligible
   external specialist after checking actual availability/permission, without
   recursive selection or another automatic health assessment.
3. Missing/denied/empty/stale/partial/throttled evidence remains distinct and can
   yield INCONCLUSIVE. Existing evaluations are interpreted, never created.
4. Existing approved windows/rows/calls survive handoff, including all metadata,
   failed/schema/corrected reads. A smaller budget or no-retry ceiling wins.
   Tool examples never override discovered actual schemas/access.
5. Evidence-only analysis requests no Azure, Python, sign-in, install or save.
   Renderer decline/absence preserves complete chat findings, no graphics reads.
6. Only a separate explicit local write/interpreter consent permits sanitized
   JSON/SVG output at agreed paths. Verify displayed SVG separately from saved
   bytes, and never query merely for the picture. No external-service execution
   follows from health; optional service actions have separate approvals.
7. Developer-selected rank/state/evidence goes to existing coordinator selection
   or direct applicable diagnostics/Foundry; no forced rank 1, reassessment or loop.
8. Optional local transaction links use collected itemId UUID/timestamps and an
   approved interpreter. Otherwise use the verified component link. Offline URL
   regression does not establish portal navigation.

Live query, renderer CLI and portal navigation cases require their own explicit
approval and bounded test plan. Existing lab/frozen exports are not reset to
exercise this integration.
