# Explicit, separately approved Foundry lifecycle selections

Reading grants no execution approval. These complete retained capabilities do
not start automatically after investigation. Select only the requested workflow,
then its current step/branch. Supplied evidence needs no Azure/Python, installation,
auth, cache, writes or jobs; insufficient evidence remains INCONCLUSIVE.
Apply [execution boundaries](execution-boundaries.md) to relevant actions.
Invocation, traffic, sensitive content, persistence, jobs/costs, edits, deployment,
RBAC and network actions each need their own applicable explicit approval.
